# Gắn link Dashboard vào gợi ý MCP, dọn cấu hình local và chốt mốc 18/11

## Mục tiêu phiên
Hoàn tất phần code cuối trước khi đóng sổ kỹ thuật: gắn sẵn đường dẫn Dashboard vào các thông báo gợi ý của cầu nối MCP, dọn biến môi trường thừa ở cấu hình web local, kiểm thử và build sạch toàn bộ dự án, đối chiếu luồng chạy thật trên Fuji và cập nhật nhật ký tiến độ đến ngày 18/11.

## Đã làm
- **Cầu nối MCP luôn trả kèm link Dashboard khi cần chủ ví duyệt quyền:** Khi agent gọi thử hoặc gọi API quen mà bị chặn vì chưa vào danh sách quen, vượt hạn mức chi tiêu hay đang bật khóa khẩn cấp, phần gợi ý trả về luôn kèm sẵn đường dẫn Dashboard (mặc định `http://localhost:3000`, hoặc đổi sang link Vercel khi chạy online) kèm hướng dẫn mở web để ký duyệt bằng ví Privy; MCP vẫn tuyệt đối không giữ khóa chủ.
- **Cập nhật hướng dẫn & cấu hình mẫu:** Bổ sung biến mẫu đường dẫn Dashboard kèm ghi chú khi triển khai online và cập nhật mục hướng dẫn MCP trong tài liệu dự án.
- **Dọn cấu hình local an toàn:** Kiểm tra và xóa bỏ dòng biến thừa cũ không còn code nào dùng tới trong cấu hình web nội bộ mà không làm thay đổi hay lộ bất kỳ khóa bí mật nào.
- **Kiểm thử toàn diện, build & chạy thử thật trên Avalanche Fuji:**
  - Tất cả bộ kiểm thử tự động của agent (`33/33`), web (`77/77`), kiểm tra kiểu TypeScript, lint, build bản production cho web (sau khi tắt sạch máy chủ dev trên cổng `3000` rồi bật lại) và kiểm tra giao tiếp JSON-RPC qua stdio đều đạt 100%.
  - Kiểm tra thực tế bằng script chuẩn bị demo xác nhận cả 4 dịch vụ local (`3000`, `4021`, `4022`, `4023`) hoạt động bình thường và ví policy trên Fuji sẵn sàng (`0.034 USDC`, `0.1000 AVAX`, hộ chiếu ERC-8004 `#305` đã có sẵn từ ngày 17/11).
  - Chạy thử luồng thật qua MCP stdio: gọi thử địa chỉ lạ bị contract từ chối vượt trần Sandbox và tự ghi vào mục Bị từ chối trên Dashboard kèm link mở web; gọi địa chỉ chưa whitelist bị chặn kèm link mở web; gọi API Thời tiết đã duyệt qua được và thanh toán thật trên Fuji.
- **Cập nhật bảng theo dõi tiến độ:** Đánh dấu hoàn thành GĐ 4 và mốc 18/11 (bao gồm việc hộ chiếu ERC-8004 `#305` đã được mint trên Fuji), giữ nguyên chưa đánh dấu các phần sau 18/11 (kiểm tra bản Vercel ẩn danh, Office Hours, quay video 2–3 phút và nộp bài).
