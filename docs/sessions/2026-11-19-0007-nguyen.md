# Một lệnh cài MCP AgentLeash cho Claude Code và Antigravity

## Mục tiêu phiên
Rà lại toàn bộ yêu cầu nộp bài UniHack 2026. Sau đó biến câu "1 lệnh setup, không phải sửa tay `.json`" trong README thành sự thật, trước mắt cho Claude Code và Antigravity. Đã xong và đã cài thử trên máy Nguyên.

## Đã làm
- Có báo cáo yêu cầu nộp bài nằm ngoài repo, ở `../reports/Yêu cầu nộp bài UniHack 2026.md`. Hạn chót là 23:59 ngày 21/11, nộp trên team1vn.xyz. Form có 5 ô bắt buộc. Chỉ cần một link không mở được là cả đội bị loại. Ô Live app là tùy chọn.
- Chỉ cần gõ `npm --prefix agent run setup:mcp` ở gốc repo là cài xong MCP AgentLeash cho cả Claude Code lẫn Antigravity, không phải sửa tay file nào. Chạy lại bao nhiêu lần cũng được.
- Thêm `--print` để xem trước, lệnh sẽ không ghi gì. Thêm `--only=claude` hoặc `--only=antigravity` để chỉ cài một bên.
- Server MCP giờ tự tìm `.env` của repo, nên khởi động được từ bất kỳ thư mục nào. Server cũng không nạp khóa của chủ ví và facilitator, chỉ giữ khóa agent.
- Đã cài thật trên máy Nguyên. Claude Code báo `✔ Connected` với 3 tool. File cấu hình của Antigravity đã có server `agentleash`.

## File đã đổi
| File | Đổi gì, vì sao |
|---|---|
| `agent/src/envFile.ts` (mới) | `loadRepoEnv()` nạp `../../.env` theo vị trí file. Biến đã có sẵn thì giữ nguyên. Bỏ qua mọi khóa `*PRIVATE_KEY` trừ `AGENT_PRIVATE_KEY`. |
| `agent/src/mcp.ts` | Gọi `loadRepoEnv()` đầu hàm `main()`. Thông báo thiếu biến giờ ghi đường dẫn tuyệt đối của `.env`. |
| `agent/src/setupMcp.ts` (mới) | Lệnh setup. Bên Claude Code: chạy `claude mcp remove`, rồi `claude mcp add --scope user`, qua `cmd.exe` trên Windows. Bên Antigravity: gộp vào `~/.gemini/config/mcp_config.json`, giữ server khác và `env` cũ, sao lưu `.agentleash.bak` một lần. |
| `agent/test/setupMcp.test.ts` (mới) | 11 test cho nạp `.env`, gộp cấu hình (file rỗng, giữ server khác, chạy lại không đổi, JSON hỏng), lệnh Claude, quoting cmd.exe, tham số và kiểm tra `.env`. Agent đạt 44/44. |
| `agent/package.json` | Thêm script `setup:mcp`. Script `mcp` bỏ `--env-file=../.env`, vì `mcp.ts` đã tự nạp. |
| `README.md` | Mục cấu hình MCP chuyển từ khối JSON phải sửa tay sang lệnh `setup:mcp`, kèm giải thích cách nạp `.env`. |

## Quyết định
- Server tự nạp `.env` thay vì đưa khóa vào mục `env` trong cấu hình agent. Lý do: khóa agent chỉ nằm ở một chỗ, và cấu hình còn đúng hai trường `command` / `args` mà agent stdio nào cũng hiểu. Đã cân nhắc file launcher riêng nhưng bỏ, vì sửa thẳng `main()` gọn hơn.
- Ghi `command` bằng `process.execPath` và `args` bằng `realpath` của `mcp.ts`. Lý do: tránh lệch phiên bản Node trong PATH của app GUI, và giữ `isEntrypoint` khớp. Đã thử thêm đường dẫn `e:/` viết thường, vẫn chạy.
- Claude Code dùng phạm vi `user`. Phạm vi `local` gắn với thư mục `agent/` nơi npm chạy nên vô dụng. Phạm vi `project` thì ghi đường dẫn riêng của máy vào repo.
- Antigravity ghi vào file chung `~/.gemini/config/mcp_config.json`, theo [tài liệu chính thức](https://antigravity.google/docs/mcp). Không ghi vào `.agents/mcp_config.json` của từng workspace.
- Chưa hỗ trợ Cursor, VS Code, Codex, Gemini CLI. Nguyên chốt làm trước cho Claude Code và Antigravity.
